# 🛒 AI-Powered Market Manager (نظام إدارة المحلات والمخازن الذكي)

نظام ويب متكامل وذكي لإدارة المحلات التجارية والمخازن والمبيعات، يجمع بين إدارة العمليات اليومية ونماذج الذكاء الاصطناعي (AI & Machine Learning) لمساعدة صاحب المتجر على اتخاذ القرارات المثلى.

---

## 🚀 التثبيت والتشغيل المحلي (Local Setup)

### 1. استنساخ المشروع وتثبيت المتطلبات:
```bash
git clone <YOUR_REPO_URL>
cd market_manager
python -m venv .venv
# تفعيل البيئة الافتراضية:
# Windows: .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
```

### 2. تجهيز قاعدة البيانات والبيانات الأولية:
```bash
python manage.py migrate
python manage.py seed_market_data
```

### 3. تشغيل السيرفر المحلي:
```bash
python manage.py runserver 127.0.0.1:8000
```
افتح المتصفح على: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## 🌍 المشاركة عبر رابط عالمي أونلاين (Live Public Tunnel)

لمشاركة النظام مع أصدقائك أو فريق العمل عبر الإنترنت لتجربته مباشرة من هواتفهم وأجهزتهم دون الحاجة لنشر معقد:

```powershell
.\cloudflared.exe tunnel --url http://127.0.0.1:8000
```
سيظهر لك رابط عالمي فوري آمن ومجاني بصيغة:
`https://xxxxxxxxxxxx.trycloudflare.com`

## 🛠️ البنية التقنية (Tech Stack)

- **Backend:** Python 3.14 + Django 6.1.2
- **AI & Data Analysis:** NumPy + Pandas + Scikit-Learn
- **Database:** SQLite (مهيأ للانتقال السهل إلى PostgreSQL)
- **Frontend:** HTML5 + CSS3 + Bootstrap 5 RTL + Bootstrap Icons + Chart.js + Vanilla JS
- **Dark Mode Support:** وضع ليلي ونهاري متكامل مع حفظ تفضيل المستخدم في LocalStorage وسرعة استجابة فائقة دون وميض
- **Offline Engine:** LocalStorage & Idempotent UUID Sync

## 📋 المميزات الـ 19 الأساسية المكتملة (Core Features)

1. **إدارة المنتجات (Product Management):** فصل بيانات المنتج عن دفعات الشراء لتعدد أسعار التكلفة وتواريخ الصلاحية.
2. **إدارة المبيعات ونقاط البيع (Sales Management & POS):** واجهة كاشير سريعة تدعم قارئ الباركود، حساب التكلفة اللحظية والخصومات.
3. **تحليل الأرباح والبيانات المالية (Profit & Financial Analysis):** حساب محاسبي دقيق يفصل تكلفة البضاعة المباعة (COGS) عن المصروفات التشغيلية لحساب مجمل الربح وصافي الربح التشغيلي الحقيقي دون ازدواجية.
4. **إدارة المخزون والدفعات (Inventory Management):** تتبع الأرصدة عبر المخازن، تنبيهات قرب انتهاء الصلاحية ونقص المخزون، وسجل كامل لحركات الوارد والمنصرف.
5. **مراقبة نشاط الباركود (Barcode Scanner Activity):** مطابقة مسحات الباركود بالفواتير المكتملة لاكتشاف السلع الممسوحة دون إتمام بيع (Loss Prevention).
6. **ذكاء المواسم (Seasonal Intelligence):** تحليل فترات الإقبال الموسمية (رمضان، الأعياد، المدارس، الصيف).
7. **العروض والخصومات الذكية (Smart Offers):** اقتراح عروض ترويجية لتصريف السلع الراكدة أو المقتربة من الانتهاء مع الالتزام بالحد الأدنى لهامش الربح.
8. **إدارة المرتجعات (Returns Management):** تسجيل المرتجعات وربطها بالفواتير مع فحص حالة السلعة (سليم يعاد للمخزون / تالف لا يعاد للمخزون).
9. **إدارة الموردين (Supplier Management):** سجل الموردين، مهل التوريد، الحدود الدنيا للطلب، وتقييمات الالتزام.
10. **جدولة الموردين والطلب الذكي (Smart Ordering):** احتساب كميات النواقص وفق سرعة السحب اليومية ومهلة التوريد وحد الأمان.
11. **التقويم الذكي والمناسبات (Smart Calendar):** تقويم سنوي للأحداث وربطها بالفئات الأكثر تأثراً.
12. **الصفقات الاستثنائية واللوطات (Special Deals):** دراسة العروض المؤقتة غير المجدولة وحساب مجمل الربح التقديري والعائد على الاستثمار (ROI).
13. **إدارة المصروفات التشغيلية (Operating Expenses):** فواتير الكهرباء، المياه، الإيجار، المرتبات، الصيانة، والسداد الجزئي والكامل.
14. **التنبؤ بالطلب (AI Demand Forecasting):** نماذج انحدار خطي وتعلم آلي للتنبؤ بمبيعات 7 و 14 و 30 يوماً مع نطاق عدم اليقين.
15. **رصد الشذوذ والتجاوزات (AI Anomaly Detection):** رصد قفزات المصروفات غير المعتادة وفروق الجرد ومسحات الباركود غير المطابقة.
16. **التحكم البشري للتوصيات (Human-in-the-Loop AI):** التوصيات تتضمن أسباباً واضحة، مع إمكانية القبول أو الرفض أو التعديل من المدير.
17. **النسخ الاحتياطي واستعادة البيانات (Backup & Disaster Recovery):** أخذ لقطات فورية لقاعدة البيانات وحفظها وتوفير تحميلها واستعادتها.
18. **استمرارية المبيعات والمزامنة دون اتصال (Sales Continuity):** تمكين الكاشير من البيع عند انقطاع الإنترنت ومزامنة العمليات بأمان (Idempotency) فور عودة الاتصال.
19. **سجل العمليات والصلاحيات (Audit Logs & RBAC):** توثيق كل عملية حساسة (تغيير أسعار، تسويات جرد، قرارات AI) وفق أدوار المستخدمين.
